# Фото товаров: прозрачный фон

Карточки в каталоге бывают на разном фоне (белые, серые `#f6f6f8`, цветные).
Поэтому у **каждого** изображения товара фон должен быть прозрачным — тогда
одна и та же картинка ложится на любую подложку без прямоугольного стыка.

## Порядок действий

### 1. Проверить, есть ли РЕАЛЬНАЯ прозрачность

Наличия альфа-канала недостаточно: у многих PNG канал есть, но забит `255`,
а белый фон запечён в пиксели. Проверять надо содержимое канала:

```python
from PIL import Image
a = Image.open(src).convert("RGBA").getchannel("A")
lo, hi = a.getextrema()
real = lo < 250 and sum(1 for v in a.getdata() if v < 20) / (a.width*a.height) > 0.02
```

`real == False` → фон запечён, идём на шаг 2 и вырезаем.

⚠️ **Главная ловушка:** если у исходника есть альфа, НЕЛЬЗЯ делать
`.convert("RGB")` — прозрачность схлопнется в чёрный, и картинка будет
выглядеть как продукт на тёмном фоне. Однажды я на этом потерял час: увидел
«тёмные фоны», начал их вырезать и выел белые части у MacBook и PS5.

Есть альфа → **ничего не вырезаем**, только кроп + ресайз (шаг 3).

### 2. Нет альфы (JPG, белый/светлый фон) — заливка от периметра

Заливку пускаем от **всех** пикселей по периметру, а не от 4 углов: у товара
часто есть тень или градиент, и из одного угла фон целиком не заливается.

```python
from PIL import Image, ImageDraw, ImageFilter
im = Image.open(src).convert("RGB")
w, h = im.size
work, KEY = im.copy(), (255, 0, 255)
seeds = [(x, 0) for x in range(0, w, 6)] + [(x, h-1) for x in range(0, w, 6)] \
      + [(0, y) for y in range(0, h, 6)] + [(w-1, y) for y in range(0, h, 6)]
for s in seeds:
    if work.getpixel(s) != KEY:
        try: ImageDraw.floodfill(work, s, KEY, thresh=THRESH)
        except Exception: pass
px = work.load()
alpha = Image.new("L", (w, h), 255); ap = alpha.load()
for y in range(h):
    for x in range(w):
        if px[x, y] == KEY: ap[x, y] = 0
alpha = alpha.filter(ImageFilter.GaussianBlur(0.7))   # мягкий край
out = im.convert("RGBA"); out.putalpha(alpha)
```

**Порог `THRESH` подбирать, а не брать наугад:**

| Товар | Порог | Почему |
|---|---|---|
| тёмный/цветной на белом | 35–45 | фон уходит целиком, товар не задет |
| **белый на белом** (PS5, AirPods, MagSafe) | 15–22 | выше — выест сам товар |
| с мягкой тенью/градиентом | 30–40 | иначе останется серый ореол |

Если товар светлый и порог приходится занижать — остаток фона не страшен:
на светлой карточке (`#f6f6f8`) разница почти незаметна. Выеденная дырка в
товаре заметна куда сильнее, поэтому **ошибаться лучше в сторону меньшего порога**.

### 3. Обрезка полей и ресайз

```python
bbox = out.getbbox()          # убираем пустые поля по альфе
if bbox: out = out.crop(bbox)
out.thumbnail((TARGET, TARGET), Image.LANCZOS)   # ~2.5× от размера в вёрстке (ретина)
out.save(dst, "WEBP", quality=88, method=6)
```

### 4. Обязательно проверить глазами

Собрать контрольный лист на **контрастном** фоне (ярко-розовый) — сразу видно
и остатки фона, и выеденные части товара:

```python
sheet = Image.new("RGB", (cols*cell, rows*cell), (255, 80, 160))
sheet.paste(img, (x, y), img)      # третий аргумент = маска, иначе альфа не применится
```

Смотреть именно на: белые корпуса (дырки), тонкие детали (кабели, ножки),
контуры (ореол). Только после этого класть в `dist/`.

## Готовый скрипт

`scripts/cutout.py` в этой папке делает всё сразу:

```bash
python3 cutout.py --src assets/prod --out dist/img --prefix prod- --size 560
python3 cutout.py --src assets/prod --out dist/img --prefix prod- --thresh 18   # для белых товаров
python3 cutout.py --check /tmp/sheet.png --out dist/img --prefix prod-          # контрольный лист
```

## Не забыть

- **Версионировать** файлы (`?v=<хэш>`), иначе браузер отдаст старую картинку
  и правка «не увидится».
- Товарные фото с сайта поставщика часто отдаются превьюшками: в URL бывает
  `/-/resizeb/x20/` — вырезать этот кусок, чтобы забрать оригинал.
- Не выдавать ИИ-рендеры за фото реального товара: для витрины это плейсхолдер,
  к продакшену нужны настоящие снимки.
