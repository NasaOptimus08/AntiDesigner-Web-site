# 🎤 Диктовка

Системная голосовая печать для macOS. Локально, бесплатно, без лимитов, только русский.

**Как работает:** жмёшь горячую клавишу → говоришь → жмёшь ещё раз → текст сам
вставляется туда, где стоит курсор (Telegram, Claude Code, редактор сценария —
куда угодно). Распознаёт локальный Whisper `large-v3-turbo`, интернет не нужен.

---

## Запуск

```bash
~/dictate/run.sh
```

Оставь это окно терминала открытым — это и есть работающая утилита.
Выход — `Ctrl+C`.

По умолчанию горячая клавиша **⌘ + ⇧ + D**. Нажал → пошла запись (звук «тинк»),
надиктовал, нажал ещё раз (звук «поп») → через пару секунд текст вставится
(звук «стекло»).

---

## Первый запуск: выдать 2 разрешения

macOS спросит их сам, либо задай вручную в **Системные настройки → Конфиденциальность и безопасность**:

1. **Микрофон** → включить для **Терминала** (или iTerm — смотря откуда запускаешь).
2. **Универсальный доступ (Accessibility)** → включить для **Терминала**.
   Нужно, чтобы ловить горячую клавишу и вставлять текст в чужие окна.

После включения Accessibility — перезапусти утилиту (`Ctrl+C` и снова `run.sh`).

---

## Настройки (вверху файла `dictate.py`)

| Параметр | Что меняет |
|---|---|
| `HOTKEY` | Горячая клавиша. Напр. `'<f17>'`, `'<ctrl>+<alt>+space'` |
| `MODEL` | Модель. `ggml-small.bin` — быстрее, но грубее |
| `MIC_PREFERENCE` | Приоритет микрофонов по имени (сейчас RODE → встроенный) |
| `INSERT_MODE` | `paste` (Cmd+V) или `type` (посимвольно) |
| `NOTIFY` | Показывать всплывающее уведомление с результатом |

---

## Автозапуск при входе в систему (по желанию)

Системные настройки → **Основные → Объекты входа** → «+» → добавить `run.sh`.
Либо: `Программы → Automator → Программа → «Запустить shell-скрипт»` со строкой
`~/dictate/run.sh`, сохранить как приложение и добавить в объекты входа.

---

## Если что-то не так

- **Ничего не записалось** → не выдан доступ к Микрофону, либо не тот микрофон
  (проверь имя в `MIC_PREFERENCE` и что устройство подключено).
- **Горячая клавиша не срабатывает / текст не вставляется** → не выдан
  Accessibility, или после выдачи не перезапустил утилиту.
- **Долго распознаёт** → большой фрагмент; для коротких реплик можно поставить
  `ggml-small.bin` в `MODEL`.
