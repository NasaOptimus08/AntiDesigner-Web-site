# Приложение для голосовой диктовки

Локальная голосовая печать: жмёте горячую клавишу → говорите → жмёте ещё раз →
текст сам вставляется туда, где стоит курсор (Claude Code, Telegram, редактор).
Работает офлайн через локальный Whisper, без подписок и лимитов. Именно так
Дмитрий надиктовывает промты и сценарии.

В архиве исходники под **macOS**. Под Windows аналог собирается через Claude Code
(см. ниже).

---

## Самый простой способ (и для Mac, и для Windows)

Закиньте этот архив прямо в Claude Code и напишите:

> Вот исходники приложения для голосовой диктовки под macOS. Установи и настрой
> его у меня: поставь зависимости (whisper, ffmpeg, python-окружение), собери
> приложение и объясни, какие разрешения выдать. Горячую клавишу дай мне назначить
> свою.

Если у вас **Windows**:

> Вот исходники приложения голосовой диктовки под macOS (Whisper + горячая
> клавиша → вставка текста в активное окно). Собери мне такое же под Windows:
> локальный Whisper, запись с микрофона, распознавание по горячей клавише и
> вставка распознанного текста туда, где курсор. Назначь мне горячую клавишу и
> объясни, как запускать при старте системы.

Claude Code разберётся с зависимостями сам под вашу систему.

## Если ставите на Mac руками

Нужны: Python 3.9+, `ffmpeg`, `whisper-cli` (whisper.cpp) и модель
`ggml-large-v3-turbo.bin`. Дальше:

```bash
# запуск из терминала (простой вариант, окно держать открытым)
./run.sh
```

Первый запуск попросит два разрешения в Системных настройках →
Конфиденциальность и безопасность:

1. **Микрофон** — для терминала (или для собранного приложения).
2. **Универсальный доступ (Accessibility)** — чтобы ловить горячую клавишу и
   вставлять текст в чужие окна. После выдачи — перезапустить.

Собрать полноценное приложение в строке меню:

```bash
python setup.py py2app
# результат: dist/Диктовка.app → перетащить в Программы
```

## Горячая клавиша и настройки

В начале файла `dictate.py` (простой вариант) или `dictate_app.py` (менюбар)
меняются:

- **горячая клавиша** (по умолчанию своя, назначьте удобную);
- **модель** (`ggml-small.bin` быстрее, но грубее);
- **микрофон** (приоритет по имени устройства);
- **автозамены** (`REPLACEMENTS`) — впишите свои термины парами «как услышал →
  как надо», чтобы Claude Code, Figma и прочее писались правильно.

---

## Как пользоваться в работе

1. Открыли Claude Code, поставили курсор в поле ввода.
2. Нажали горячую клавишу, надиктовали задачу своими словами: «разбери нишу
   такого-то клиента, собери прототип, дай список вопросов на созвон».
3. Нажали клавишу ещё раз — текст вставился. Отправили.

Диктовать быстрее, чем печатать: длинную задачу проговариваете за минуту вместо
десяти.
