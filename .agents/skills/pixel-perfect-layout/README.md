# Скилл «pixel-perfect-layout» — установка в Claude Code

Скилл учит Claude верстать блоки «пиксель-в-пиксель» по макету (Figma или скриншот)
и САМОМУ проверять свой результат: рендер → скриншот → сверка с эталоном → правки,
и так до совпадения.

## Установка (1 минута)

Скилл — это папка `pixel-perfect-layout/` с файлом `SKILL.md` внутри.
Положи её в одно из двух мест:

**Вариант 1 — для одного проекта:**
```
<папка твоего проекта>/.claude/skills/pixel-perfect-layout/SKILL.md
```

**Вариант 2 — для всех проектов сразу (глобально):**
```
~/.claude/skills/pixel-perfect-layout/SKILL.md
```
(`~` — твоя домашняя папка; на Mac это /Users/имя, на Windows — C:\Users\имя\.claude\...)

После этого перезапусти Claude Code (или начни новую сессию).

## Как пользоваться

1. Дай Claude эталон: выделенный фрейм в Figma (точнее) или скриншот блока.
2. Скажи ширину экрана макета (например, 1728 или 1440) и какие шрифты используются.
3. Попроси: «сверстай этот блок пиксель-в-пиксель» — скилл подхватится сам,
   либо вызови его явно: `/pixel-perfect-layout`.

Claude сверстает блок, откроет его в превью на нужной ширине, снимет скриншот,
сам найдёт расхождения с макетом (размеры, отступы, цвета, шрифты), исправит
и повторит цикл, пока не совпадёт.

## Figma MCP (опционально, но сильно точнее)

Если у тебя Figma с Dev Mode (тариф Professional+), подключи официальный
Figma MCP — Claude будет тянуть точные px/цвета/шрифты прямо из макета.
Инструкция — внутри SKILL.md, раздел «Подключение Figma MCP».
