# Скилл «Незаметная замена лица» (face-swap)

Обновлено: 07.08.2026

Скилл для Claude Code: помогает заменить лицо на фотографии так, чтобы оно не выглядело
вклеенным. Лицо перерисовывается внутри сцены и подгоняется под её свет, цвет и зерно.

## Установка

**Самый простой способ.** Киньте этот архив прямо в Claude Code и напишите:
«установи этот скилл». Он сам всё разложит. Перезапустите Claude Code.

**Руками.** Распакуйте архив и положите папку `face-swap`:

- в проект: `папка_проекта/.claude/skills/face-swap/`
- или глобально для всех проектов: `~/.claude/skills/face-swap/`

Затем перезапустите Claude Code (или начните новую сессию).

## Как пользоваться

Отдельно вызывать не нужно, Claude Code подхватит скилл сам. Достаточно написать:

> Вот сцена и вот портрет человека. Собери промт по скиллу face-swap, чтобы заменить лицо
> в сцене на лицо с портрета.

Дальше генерируете по промту несколько вариантов, выбираете лучший и при необходимости
дорабатываете в Photoshop.
