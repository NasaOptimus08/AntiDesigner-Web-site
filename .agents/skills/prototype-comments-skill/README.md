# Скилл «Прототип с комментариями» (prototype-comments)

Обновлено: 25.08.2026

Скилл для Claude Code: собирает блочный вайрфрейм-прототип сайта «серыми блоками»
для согласования с клиентом до дизайна. Каждый блок подписан, клиент может
оставлять комментарии прямо на прототипе.

## Установка

**Самый простой способ.** Киньте этот архив прямо в Claude Code и напишите:
«установи этот скилл». Он сам всё разложит. Перезапустите Claude Code.

**Руками.** Распакуйте архив и положите папку `prototype-comments`:

- в проект: `папка_проекта/.claude/skills/prototype-comments/`
- или глобально: `~/.claude/skills/prototype-comments/`

Затем перезапустите Claude Code.

## Как пользоваться

1. Сначала попросите Claude Code разобрать нишу клиента (аудитория, конкуренты,
   что улучшать).
2. Затем: «Собери прототип сайта по скиллу prototype-comments на основе этого
   разбора».
3. Покажите клиенту, соберите комментарии, дорабатывайте.

В комплекте: SKILL.md (методика), comments.js и server.js — готовые файлы для
системы комментариев на прототипе.
