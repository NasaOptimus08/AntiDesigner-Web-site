# Чистая типографика (RU) для сайтов и прототипов

Правило: **любой видимый текст, который уходит на страницу, оформляется по этому
канону** — вне зависимости от проекта. Три вещи: (1) нет висящих предлогов,
(2) строки ровные, (3) нет длинных тире.

**Область действия:** только видимый текст на страницах (заголовки, абзацы, кнопки,
подписи, тексты прототипов). НЕ трогает код, атрибуты, URL, ответы в чате.

---

## 1. Неразрывные пробелы (нет висящих предлогов)

Короткие слова не должны висеть в конце строки в одиночестве. Между таким словом и
соседним ставим **неразрывный пробел** — символ U+00A0 (в JSX пишется прямо в строку;
в HTML можно `&nbsp;`; в JSX-выражении `{' '}`).

**Клеим к СЛЕДУЮЩЕМУ слову** (предлоги и союзы, стоят перед словом):
в, во, с, со, к, ко, о, об, у, и, а, но, да, из, от, до, по, за, на, под, над, при,
про, без, для, не, ни, что, как, или, чем, где, же, то, если, между, через

**Клеим к ПРЕДЫДУЩЕМУ слову** (частицы, стоят после слова): бы, б, же, ж, ли, ль

**Ещё неразрывные:**
- Число + единица/слово: `5 кг`, `10 %`, `2990 ₽`, `2024 год`, `1 на 1`, `3 бассейна`.
- Сокращения: `и т. д.`, `и т. п.`, `т. е.`, `и др.`, `г. Москва`, `ул. Ленина`.
- Знаки: `№ 5`, `§ 3`. Инициалы: `А. С. Пушкин`.
- Дефисные частицы `-то`, `-либо`, `-нибудь`, `кое-` — это дефис, НЕ пробел, не трогаем.

Пример: `в воде`, `с нуля`, `не умеете`, `для детей`, `2990 ₽ в месяц`.

**Быстрый способ проставить** — прогнать текст через хелпер (см. `assets/nbsp.py`):
```
python3 ~/.claude/skills/clean-typography/assets/nbsp.py "Плавание для детей с нуля"
# → Плавание для детей с нуля  (короткие слова склеены неразрывными)
echo "$HTML" | python3 ~/.claude/skills/clean-typography/assets/nbsp.py --stdin --entity
# --entity выдаёт &nbsp; вместо символа U+00A0; HTML-теги не трогаются
```
Скрипт консервативен: клеит только по спискам выше, внутрь `<тегов>` не лезет. После
прогона всё равно **просмотреть глазами** — язык живой, редкие случаи скрипт пропускает.

## 2. Ровные строки (баланс)

Плохо: строка 10 слов / строка 2 слова. Хорошо: строка 5–6 слов / строка 4–5 слов —
строки примерно равной длины.

**CSS (положить в глобальные стили проекта — работает само на всём тексте):**
```css
h1, h2, h3, .h1, .h2, .h3 { text-wrap: balance; } /* заголовки: строки выравниваются по длине */
p, .lead, li, figcaption   { text-wrap: pretty;  } /* абзацы: не оставляет «сироту» в последней строке */
```
`balance` — для коротких блоков (заголовки, ≤ ~6 строк): браузер сам делит поровну.
`pretty` — для длинных абзацев: чинит только последнюю строку, дешевле по перфу.

**Правила, без которых баланс не сработает:**
- **НЕ задавать фиксированную `width` на заголовке/абзаце** — фикс-ширина ломает
  `text-wrap: balance`. Нужно сузить → `max-width` + `margin: 0 auto`, не `width`.
- Заголовок целимся в **2 строки**. 3 строки — только если текст физически не влезает в
  2 в реально узком контейнере. Если влезает — **сокращать текст**, а не расширять блок.
- Описание/абзац на десктопе — минимум 2 строки примерно равной длины.
- Где нужен ручной контроль переноса (точно знаешь, где ломать) — ставь неразрывный
  пробел там, где рвать НЕЛЬЗЯ, и/или `<br>` там, где рвать НАДО. `balance` это уважает.

**Ловушка:** `text-wrap: balance` не действует, если у элемента задан `width`,
`white-space: nowrap`, или он `display:flex/inline`-ребёнок без своей ширины. Заголовок
должен быть блочным и без фикс-ширины.

## 3. Без длинных тире

Символы `—` (em dash) и `–` (en dash) в видимом тексте **не использовать** — читается как
нейростиль. Заменять:
- пауза/пояснение → двоеточие или запятая: `Плавание: с нуля до уверенности`;
- перечисление/приложение → переписать фразу или запятой;
- диапазон (`5–10`) → дефис `5-10` или предлоги `от 5 до 10`.

Дефис-минус в CSS/коде (`letter-spacing:-.5px`, `margin:-4px`) — это НЕ тире, оставляем.

## Как применять в разных стеках

- **Next.js / JSX:** неразрывный — символ U+00A0 прямо в строке (`в воде`). В выражениях
  `{' '}`. CSS-баланс — в глобальный `globals.css`/тему. Не ставить `style={{width}}`
  на заголовки/`.lead`.
- **Чистый HTML (лендинг/прототип):** `&nbsp;` в тексте (или прогнать `nbsp.py --entity`);
  CSS-баланс — в общий `<style>`/файл темы.
- **Вайрфрейм-прототип** (скилл `wireframe-prototype`): тексты пишем начисто и сразу по
  этому канону — клиент читает уже ровный текст, а не рваный.

## Чеклист перед сдачей текста / деплоем

- [ ] Короткие предлоги/союзы приклеены неразрывным (нет висящих `в`, `с`, `и`, `на`…)
- [ ] Частицы `бы/же/ли` приклеены к предыдущему слову
- [ ] Числа с единицами неразрывны (`2990 ₽`, `3 бассейна`, `10 %`)
- [ ] Заголовки — 2 строки, строки примерно равной длины (нет «5 слов / 1 слово»)
- [ ] В CSS есть `text-wrap: balance` на заголовках и `pretty` на абзацах
- [ ] Нет `style={{ width }}` на заголовках/`.lead` (только `max-width`)
- [ ] В видимом тексте нет `—` и `–` (заменены на `:` / запятую / переписаны)
